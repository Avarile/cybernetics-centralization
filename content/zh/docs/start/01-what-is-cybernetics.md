Cybernetics 是一份属于你的记忆，任何 AI 都能接入。它由四个应用组成，可以单独使用，也可以组合使用；每一个都支持 MCP——AI 应用读写你数据时使用的标准接口。

## 四个模块

| 模块 | 存放什么 | 基于 |
|---|---|---|
| **数据库** | 你知道什么：笔记和操作指南、目标和项目、人脉、财务，都放在你自己设计的关联表格里 | Teable |
| **项目管理** | 你在做什么：项目、周期和工作项，可以分配给人，也可以分配给智能体 | Plane |
| **CRM** | 你和谁共事：人员、公司、商机、笔记和跟进 | Twenty |
| **智能体平台** | 谁替你行动：使用另外三个模块的自定义智能体和技能，可运行在任何模型上 | LibreChat |

从**数据库**开始。它是地基，可以独立运行，每一篇指南也都从它讲起。其余的，需要时再加。

## 它们如何连接

- **你的 AI → 每个模块。** Claude、ChatGPT、Codex、Cursor 或智能体平台，用你创建、可随时撤销的密钥连接到模块的 MCP 端点。参见[连接你的 AI](/docs/connect/overview)。
- **项目管理 → 数据库。** 工作项可以携带数据库记录，任务到手时就带着所需的经验。
- **CRM → 数据库。** 人员、公司和商机都有一个 Database 标签页，用来关联记录。
- **智能体平台 → 全部三个。** 智能体读取你的知识，领取分配给它们的工作，并把做过的事写回去。

## 托管还是自托管

| | 托管（抢先体验） | 自托管 |
|---|---|---|
| 适合谁 | 任何人 | 熟悉 Docker 和服务器的技术用户 |
| 设置 | 我们为你开通账号 | 你自己运行整套系统；参见自托管文档 |
| 支持 | 抢先体验期间一对一支持 | 社区 |
| 你的数据 | 在我们的服务器上，由你的密钥保护 | 在你自己的服务器上 |

两种方式都可以[注册抢先体验](/register)。我们会帮你上手。
